Refused

A tool asked to change a config that cannot change while the broker runs. Kafka says no, and so does this broker, in the same words. The console never offers it; this is what kafka-configs.sh or another client would see.

[[g:back 16]]Back to Settings
[[g:warn 18]]
Refused INVALID_REQUEST (42)
Cannot update these configs dynamically: [num.partitions]
The rule: only five broker configs act on a running broker. num.partitions is read once, at start.

What would pass

Start the broker with the flag that sets it. For num.partitions that is --default-partitions, now 1.

--default-partitions 3All flags

The other ways a change is refused

All are INVALID_REQUEST (42), with Kafka's text. The first is the one above.
