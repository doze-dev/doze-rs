Create an ACL

Topic[[g:chev-d 14]]
Literal names this topic only. Prefixed covers every name that starts with it.
Write[[g:chev-d 14]]
Kafka says an ACL covers a resource when its name matches; once one does, the default no longer applies to that resource.
Allow implies Describe for Read, Write, Delete and Alter. Deny is exact: Deny Read does not deny Describe, and a Deny wins over any Allow.
Host is * or the client's address as text, not a range.
