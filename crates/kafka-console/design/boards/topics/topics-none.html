This broker holds no topics

A topic is a named log of records, split into partitions. Create one here, or let a client make it: --auto-create-topics is on, so the first request for a name that does not exist creates it with --default-partitions (1).

[[g:plus 16]]Create topic

Or from your app

Writing to a topic that does not exist creates it, and the console shows it here as soon as the request lands.

# kcat, from the machine the broker runs on
echo '{"order_id":"ord-88412"}' | kcat -P -b 127.0.0.1:9092 -t orders -k ord-88412
To 127.0.0.1:9092, the listener
