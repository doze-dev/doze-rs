[[g:info 18]]
What can refuse this call
A name that already exists, a name that collides with one by . and _, a partition count outside 1 to 1,000, a config value Kafka would not accept. Check only runs every one of those checks and creates nothing. If a client makes orders.retry while you read this, the call is refused: see that refusal.
[[g:api 14]]The call
CreateTopics v7
  topics[0]
    name: orders.retry
    num_partitions: 3
    replication_factor: 1
    configs:
      cleanup.policy = delete
      retention.ms = 604800000
  validate_only: false
[[g:code 14]]Or from a terminal
# the same, with Kafka's own tool
kafka-topics.sh --bootstrap-server 127.0.0.1:9092 \
  --create --topic orders.retry --partitions 3 \
  --config cleanup.policy=delete \
  --config retention.ms=604800000
