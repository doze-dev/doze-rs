The key and time filters read the log from the start of the partition; an offset goes straight to the batch that holds it.

Why filter by offset

Ask for exactly the records you want to look at.

A Fetch names a partition and an offset and gets whole batches from the one that holds it, up to the byte limit. Asking from 16,098 returns the first record of the open transaction onward. A key search has no such shortcut: it reads from the start of the partition.
