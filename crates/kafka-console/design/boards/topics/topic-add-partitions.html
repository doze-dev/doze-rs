adds 2: orders-3 and orders-4
Kafka says the new total, not the number to add.
Default none; it must be above 3.
Range 4 to 1,000 (--max-partitions).
Takes effect at once: producers and consumers see the new partitions in their next Metadata. They start empty.
Here records with the same key may now hash to a different partition, so order for a key is not kept across the change.
ignored: this broker is the only replica
Never fewer. To get fewer partitions, create a new topic. Try a count of 2: see the refusal.
