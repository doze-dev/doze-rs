Kafka says legal characters are ASCII letters and digits, . _ and -, at most 249 of them.
Default none: a topic needs a name.
Range 1 to 249 characters, not . or ...
Takes effect at once; the name can never be changed, only deleted and made again.
Here a.b and a_b collide, and names that differ only in letter case are refused. The name is free.
of 1 to 1,000
Kafka says the number of partitions to create in the topic, or -1 for the default.
Default 1 here (--default-partitions).
Range 1 to 1,000 (--max-partitions); above that is refused INVALID_PARTITIONS.
Takes effect at once. It can be raised later, never lowered.
Here order is kept inside a partition only. One broker holds all of them, with replication factor 1.

[[g:api 14]]The call
CreateTopics v7
  topics[0]
    name: orders.retry
    num_partitions: 3
    replication_factor: 1
    configs: (none yet: all defaults)
  validate_only: false

Replication factor is always 1: this broker is the only broker.

[[g:code 14]]Or from a terminal
# the same, with Kafka's own tool
kafka-topics.sh --bootstrap-server 127.0.0.1:9092 \
  --create --topic orders.retry --partitions 3 \
  --config cleanup.policy=delete
