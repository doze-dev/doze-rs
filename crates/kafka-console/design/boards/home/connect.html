Connect an app

It is an ordinary Kafka broker, so it is an ordinary Kafka client. Only the address is yours to fill in; here it already is.

Address

Bootstrap from this address. Clients are then told where to reconnect.

127.0.0.1:9092
The listener, set by --listen. It is on loopback, so only this machine can reach it.

From another machine or a container

Listen on every interface and advertise an address the other side can use. Why the advertised host matters.

doze-kafka --listen 0.0.0.0:9092 \
  --advertised-host 192.168.1.20 \
  --advertised-port 9092

Advertised listener

Reachable

After Metadata a client reconnects to the advertised address. This broker advertises 127.0.0.1:9092, which is the address it listens on, and answers there.

Name your app

Set client.id to the app's own name. The wire shows every request under that name, so payments and fulfilment appear as themselves, not as a default like rdkafka.

No credentials needed. The top bar says Open: any client that can reach the address may connect. If SASL is on, add the three lines below. Access lists the mechanisms the broker offers.
[[g:lock 16 d-config]]

When SASL is on

These are Kafka's own client settings. Use SASL_SSL when the broker serves TLS; a PLAIN password crosses the network as it is without it.

security.protocol=SASL_PLAINTEXT
sasl.mechanism=SCRAM-SHA-256
sasl.jaas.config=org.apache.kafka.common.security.scram.ScramLoginModule required \
  username="<user>" password="<password>";
