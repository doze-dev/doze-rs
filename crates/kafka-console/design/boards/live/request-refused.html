Kafka's words
Compacted topic cleanup.policy=compact requires every record to have a key

The rule

A compacted topic keeps the latest value for each key. A record with no key has nothing to be the latest of, so the broker refuses the batch and writes none of it.

A key with an empty value is also a valid record: a tombstone, which deletes that key at compaction.
