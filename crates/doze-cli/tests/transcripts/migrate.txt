# migrate: a module instance's data moved to the major doze.hcl declares, by its module (the daemon's migrate call;
# nothing module-specific in the CLI). doze.hcl answers first: a name it does not declare is exit 4, an app is not a
# module (exit 1). The dry run says what would happen, and the move; the run prints what the module said of it.
@ project shop
@ daemon migrate
