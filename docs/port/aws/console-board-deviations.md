# Where the console does not do what a board says

The boards of the design canvas (`8fb38ec7-de4e-4570-b8c8-d1eabfe70929`) are the spec for the doze-aws console, with one exception:
a board that says something false of doze-aws, or asks for something doze-aws cannot do, is built to what the backend does. Each
such case is a row here, written by the slice that met it. The canvas is not edited.

A row says which board, what the board says, what the backend does (with the file that shows it), and what was decided.
| Board | What the board says | What the backend does | Decision |
| --- | --- | --- | --- |
| `sqs__queue-delete`, `sqs__queue-deleted`, `sqs__queue-purge`, `sqs__queue-purged` | A delete and a purge are at once, and `--sqs-strict` is the flag that makes doze-aws refuse a re-create or a second purge for 60 seconds. | The wait is the default, as on AWS: `QueueDeletedRecently` and `PurgeQueueInProgress` are answered unless doze-aws starts with `--sqs-skip-60s-waits`; there is no `--sqs-strict` (`crates/aws-sqs/src/queues.rs`, `crates/doze-aws/src/keys.rs`). | The copy says what happens: AWS and doze-aws refuse for 60 seconds, and `--sqs-skip-60s-waits` lifts it. The e2e purges twice and sees `PurgeQueueInProgress`. |

| `sqs__queue-encryption`, `sqs__queue-detail`, `sqs__queues-list` | `Enabled with SSE-KMS` for a queue with a key. | `GetQueueAttributes` reports `SqsManagedSseEnabled` as `true` whether or not a KMS key is set (`crates/aws-sqs/src/attrs.rs`, `attributes`); AWS reports `false` with a key. | The page reads a `KmsMasterKeyId` as SSE-KMS and otherwise `SqsManagedSseEnabled` as SSE-SQS (`sqs/queue-model.ts`). | `sqs__queue-create`, `-create-fifo` | Every field carries a hint from the neighbours (`pick-lists uses 30 seconds. pick-lists keeps 4 days; pick-lists-dlq keeps 14`). | The list reads a queue's name and counts, not its settings; a queue's settings are one `GetQueueAttributes` each. | The hints are those of the queue whose name is typed, when it exists (its detail is read): `pick-lists already exists in this Region`, its visibility timeout and retention. | `sqs__queue-create-refused` | `QueueNameExists: a queue named pick-lists already exists with a different value for VisibilityTimeout.` | The words are the service's: `A queue already exists with the same name and a different value for attribute VisibilityTimeout` (`crates/aws-sqs/src/queues.rs`). | The banner, the field and the call panel carry the service's words and code; the attribute is read out of them and the existing queue's value is shown beside the form. |
| `sqs__queue-sns-subscribe` | `3 subscriptions, all SQS, with raw message delivery off`. | Reading each subscription's delivery attributes is a read per subscription. | The topic's name and its ARN are said; the raw-delivery setting is left out. | `sqs__queues-list`, `sqs__queue-detail`, `sqs__message-detail`, `sqs__dlq-redrive-*` | Times as `Nov 6, 2026 18:42`. | The console writes every time as `2026-11-06 18:42:00 UTC` (`@doze/ui/lib/format`). | The console's own format, as on every page. |

## How a slice adds a row

Append a row in the table above, in the same commit as the code that departs from the board. Name the board exactly, quote what it
says, say what the backend does and where, and say the decision (built to the backend, or deferred with the owner's reason).
