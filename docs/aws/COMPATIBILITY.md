- **Built** counts the operations in AWS's own model of the API that this build serves. The rest are refused by name (HTTP 501, header `X-Doze-Not-Built`), never answered wrongly.

## Everywhere

- Requests are not signature-checked by default (`--auth trust`): any access key works, as with most local AWS tools. `--auth verify` checks every SigV4 signature against the configured key and the keys IAM issues.
- IAM refusals are logged and let through by default (`--iam soft`), so a missing permission is a warning in development rather than a failure. `--iam enforce` refuses as AWS does; `--iam off` skips evaluation.
- One account (`--account`, default 000000000000) and every region, each region kept apart on disk.
- Nothing leaves the machine unless a target says so: SMS, email and mobile push are accepted and sent nowhere; HTTP(S) subscriptions, API destinations and webhooks are really called.
- CloudFormation makes the resources of the services doze-aws runs. A resource of a service it does not run (Cognito, ECS, AppSync, load balancers...) is not created: the stack carries on, the resource reports CREATE_COMPLETE with a status reason saying so, and a warning is logged.
